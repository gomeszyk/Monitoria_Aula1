# 🐾 Monitoria — Introdução a React

![React](https://img.shields.io/badge/React-19-149ECA?logo=react&logoColor=white) ![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite&logoColor=white)

Repositório de uma atividade de monitoria com um projeto inicial chamado **Cemitério de Pets**, criado para praticar a estrutura de uma aplicação React.

## 📁 Estrutura

```text
Monitoria_Aula1/
└── Cemiterio_de_Pets/
    ├── public/
    ├── src/
    │   ├── App.jsx
    │   ├── Componentes/
    │   └── assets/
    └── package.json
```

## ▶️ Executar

```bash
cd Cemiterio_de_Pets
npm install
npm run dev
```

Requer Node.js e npm. O Vite informará a URL do servidor local.
